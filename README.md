# CUSHION-ANKETO - LP派生プロジェクト

## 📁 フォルダ構成

```
xserver-upload/
├── cushion-anketo-common/          # 共通リソース
│   ├── public/                 # 画像リソース
│   ├── styles.css              # 共通CSS
│   └── script.js               # 共通JavaScript
├── cushion-anketo-1/               # 派生LP
│   └── index.html
├── cushion-anketo-2/               # 派生LP
│   └── index.html

## 🚀 Xserverへのアップロード方法

1. FTPクライアント（FileZilla等）でXserverに接続
2. `public_html/` ディレクトリに移動
3. このフォルダ（xserver-upload）内の全ファイルをアップロード
